# Method figure

Run `python figures/draw_method_overview.py` from the repository root to rebuild the paper diagram and README preview. The drawing code is in `paper/figures/draw_method_main.py`.

The paper uses the vector PDF, with selectable text. The README displays a PNG and links to the SVG, where the labels remain text. The wide, numbered panels follow the equations and update order in Table 2 of the paper.
